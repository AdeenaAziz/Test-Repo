# Python for DevOps -: PostgreSQL Database Interaction

A comprehensive guide on connecting to PostgreSQL databases and performing CRUD operations using Python.

## 📋 Prerequisites

### Software Requirements
- **PostgreSQL** (Version 16 or compatible)
- **Python** (3.6 or higher)
- **Java JDK** (Version 17 recommended)
- **psycopg2** Python package

### Installation Steps

1. **Install PostgreSQL**
   - Download from [official PostgreSQL website](https://www.postgresql.org/download/)
   - During installation:
     - Remember the `postgres` user password
     - Note the port (default: `5432`)
     - Select "Web Development" package for minimal setup

2. **Install Java JDK**
   - Required for PostgreSQL installation
   - JDK 17 recommended

3. **Install Python Package**
