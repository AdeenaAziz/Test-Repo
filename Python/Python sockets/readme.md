Python Socket Demo

This is a simple Client–Server project created while learning the Python Socket library.
It demonstrates basic network communication between two programs using TCP sockets.

Features

1. Basic socket creation

2. Server listens on a port

3. Client connects to server

4. Client sends a message

5. Server receives and prints the message

Project Files
    File	                        Description
1. server.py	Starts the server, accepts client, and receives data
2. client.py	Connects to the server and sends a messages

How to Run the Project?
1. Start the Server
python server.py

You should see:
Server is running... Waiting for connection...

2. Run the Client
python client.py
The server will then print the message sent by the client.
